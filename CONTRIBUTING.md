# Contributing

Спасибо за интерес к улучшению агентов и навыков Домового.

## Что можно улучшать

- Промпты агентов (`.config/opencode/agents/*.md`): ясность, безопасность по умолчанию, корректность делегирования.
- Навыки (`.config/opencode/skills/<id>/SKILL.md` и связанные скрипты): практические инструкции, проверки, офлайн-совместимость.
- Документация репозитория (`README.md`, `SECURITY.md` и т.д.).

## Принципы

- **Без секретов:** не добавляйте токены, пароли, ключи, приватные IP/MAC/инвентарь, бэкапы, `.env`, дампы конфигов.
- **Безопасность по умолчанию:** разрушительные/рискованные действия должны требовать явного подтверждения и сопровождаться проверкой/планом отката.
- **Проверяемость:** предпочитайте конкретные команды/шаги проверки; не описывайте недоступные в офлайн-среде зависимости как обязательные.
- **Минимальность:** одно логическое изменение на PR/коммит, понятное описание.

## Как предложить изменение

1. Сделайте форк/ветку от `main`.
2. Внесите изменения и проверьте:
   - корректность Markdown/YAML frontmatter в `SKILL.md` и агентов;
   - отсутствие секретов и приватных данных (`git diff`, поиск по ключевым словам).
3. Оформите коммит с понятным сообщением, например:
   - `feat(skill): add ...`
   - `fix(agent): clarify ...`
   - `docs: update README`
4. Откройте Pull Request с описанием: что изменено, зачем, как проверено.

## Структура навыка

```text
.config/opencode/skills/<skill-id>/
  SKILL.md          # обязателен: frontmatter (name, description) + инструкции
  ...               # опционально: вспомогательные скрипты/ресурсы (без секретов)
```

## Вопросы

Если не уверены, безопасно ли публиковать конкретный пример/фрагмент — лучше обезличить его или обсудить в issue до отправки PR.
